# 🕵🏽‍♀️ Data Detective Portfolio

**Solving fictional mysteries through data.**

Welcome to my data analytics portfolio, where investigative thinking meets SQL, Excel, and Power BI. Each project presents a unique case to investigate, using structured datasets, analytical techniques, and data visualization to uncover patterns, test hypotheses, and draw evidence-based conclusions.

From missing dogs and workplace mysteries to business problems and suspicious financial discrepancies, every case is an opportunity to ask better questions, explore the evidence, and turn raw data into meaningful insights.

## 🔎 About This Portfolio

This portfolio combines hands-on learning with practical data analytics projects. Each investigation is designed around a fictional scenario with a clear analytical objective, realistic datasets, and a documented problem-solving process.

My goals are to:

- Strengthen my SQL skills, from basic queries to joins, aggregations, and more advanced analysis.
- Develop practical Excel skills for data cleaning, calculations, analysis, and reporting.
- Learn to build informative visualizations and interactive dashboards in Power BI.
- Practice translating business questions into analytical problems.
- Communicate findings clearly, including limitations and recommendations.

## 📁 Project Structure

Each completed case will include relevant materials such as:

- **Case Brief:** Scenario, background, objectives, and investigative questions.
- **Dataset:** Fictional data, table descriptions, and data dictionaries.
- **Analysis:** SQL scripts, Excel workbooks, and other analytical files.
- **Visualizations:** Charts, dashboards, and supporting evidence.
- **Findings:** Conclusions, recommendations, and limitations.
- **Documentation:** A project-specific README explaining the process and results.

Deliverables will vary depending on the analytical goals and tools used for each investigation.

## 📊 Approach to Analysis

Every investigation begins with a question, not an assumed answer.

I aim to document the reasoning behind each analysis, validate findings against the available evidence, and distinguish between confirmed observations, plausible explanations, and conclusions that cannot be supported by the data.

All mystery scenarios and case datasets are fictional and intended for educational and portfolio purposes.

## 🚀 What's Next?

This portfolio will grow alongside my technical skills. Future projects will introduce more complex queries, data transformations, interactive dashboards, and analytical challenges.

The objective is simple: build practical skills by solving interesting problems and demonstrate how data can be used to investigate questions, uncover patterns, and support better decisions.
